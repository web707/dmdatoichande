# Feature parity matrix

The legacy status reflects source inspection and the focused Flutter, API and widget tests named here. Device-specific operation remains pending unless verified separately. Web and KMP targets describe migration work and its acceptance gate.

| Legacy feature and status | Implementation, authority and access | Web and KMP parity gate |
| --- | --- | --- |
| Home, responsive shell and More menu, existing | [app.dart](../../lib/app/app.dart), [more_page.dart](../../lib/features/more_page.dart). Public local UI. | Separate navigation. Verify desktop, narrow viewport, tablet, safe areas and system back. |
| Explore, list and accent-insensitive search, existing | [browse.dart](../../lib/features/browse.dart), [catalog.dart](../../lib/core/catalog.dart). Public `GET /api/places`, `places`, credited photos and two bundled fallbacks. `domain_test.dart`, legacy Playwright browse spec. | Implemented Phase 1 list and API search. Real Web and emulator checks cover the five destination records and search. |
| Destination detail and visit data, existing and widget-tested | [browse.dart](../../lib/features/browse.dart). Public `places`, history/culture, address, price, hours, booking, duration and source. `features_test.dart`. | Versioned detail contract matches all 18 legacy fields. Web detail verified with fixture and live API. Android detail and system Back verified on the emulator. Android detail media, source link and USD display, interactive maps and embedded tour links remain open. |
| Maps, requires platform-specific replacement | [map_page.dart](../../lib/features/map_page.dart), map preview in [forms.dart](../../lib/features/forms.dart). Public catalog coordinates, OSM tiles and attribution. `features_test.dart` verifies marker state. | Lazy Web map and native adapter. Verify provider terms, markers, offline error and attribution. Separate display from CMS changes. |
| Emergency directory, existing with fallback | [emergency_page.dart](../../lib/features/emergency_page.dart), [store.dart](../../lib/core/store.dart). Verify category and country filtering and missing fields. |
| Registration, login and logout, existing and tested | [forms.dart](../../lib/features/forms.dart), [api.dart](../../lib/core/api.dart). `users`, `sessions`, existing bearer contract and role checks. | Web HttpOnly session boundary and CSRF protection, native secure storage.
